# HLW8112 蓝牙校准协议（上位机开发说明）

本文档描述设备（HLW8112 计量芯片 + BLE 模块）与上位机之间的蓝牙数据交换协议，用于外壳安装后的无线校准。

## 1. 概述

校准流程：设备读芯片当前测量值和校准系数，通过蓝牙上报给上位机；上位机根据标准源实际值计算新的校准系数，下发回设备；设备把系数写入 HLW8112 校准寄存器（`RmsIAC`/`RmsUC`/`PowerPAC`）并持久化，完成后软复位。

- 设备本地不做任何校准计算。
- 所有多字节字段均为**小端序（Little-Endian）**。

## 2. BLE 连接参数

| 项目 | 值 |
|------|-----|
| 广播名称 | `CALIB_DEV` |
| Service UUID | `0xFD50` |
| Write 特征 UUID | `0x0001`（上位机写校准系数） |
| Notify 特征 UUID | `0x0002`（订阅后收测试数据/结果） |

上位机需要：

1. 扫描广播，按设备名 `CALIB_DEV` 过滤目标设备。
2. 连接。
3. 发现 Service `0xFD50`。
4. 找到 Write 特征 `0x0001` 和 Notify 特征 `0x0002`。
5. 订阅 Notify 特征 `0x0002`（`CCCD` 写 `0x0001` 使能通知）。

## 3. 工作流程

```
设备上电(未校准)
   └─ 广播 "CALIB_DEV"
        └─ 上位机连接 + 订阅 Notify(0x0002)
             └─ 设备每 1s 自动 Notify 测试数据(19字节)
                  └─ 上位机计算校准系数
                       └─ 上位机 Write 校准系数(7字节) 到 0x0001
                            └─ 设备写寄存器 + 存 NVS
                                 └─ 设备 Notify 结果(2字节)
                                      └─ 设备约 500ms 后软复位
```

- 设备连接后即开始**每 1 秒**主动上报一次测试数据，无需上位机请求。
- 校准系数写入成功后，设备会立即软复位；软复位后已校准，不再广播 `CALIB_DEV`。

## 4. 帧格式

### 4.1 测试数据（设备 → 上位机，Notify）

长度 **19 字节**，连接后每 1s 自动上报一次。

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | cmd | u8 | `0x01` |
| 1..4 | voltage_mv | u32 LE | 当前电压 (mV) |
| 5..8 | current_ma | u32 LE | 当前电流 (mA) |
| 9..12 | power_mw | u32 LE | 当前有功功率 (mW) |
| 13..14 | iac | u16 LE | 当前 RmsIAC 系数 |
| 15..16 | uc | u16 LE | 当前 RmsUC 系数 |
| 17..18 | pac | u16 LE | 当前 PowerPAC 系数 |

### 4.2 下发校准系数（上位机 → 设备，Write）

长度 **7 字节**。

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | cmd | u8 | `0x02` |
| 1..2 | iac | u16 LE | 新的 RmsIAC 系数 |
| 3..4 | uc | u16 LE | 新的 RmsUC 系数 |
| 5..6 | pac | u16 LE | 新的 PowerPAC 系数 |

### 4.3 校准结果（设备 → 上位机，Notify）

长度 **2 字节**，设备写入校准系数后回复。

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | cmd | u8 | `0x02` |
| 1 | result | u8 | `0`=成功，`1`=失败 |

## 5. 校准系数计算（上位机侧）

上位机收到测试数据后，结合标准源实际值计算新系数：

```
iac_new = round( iac × 标准电流(mA) / current_ma )
uc_new  = round( uc  × 标准电压(mV) / voltage_mv )
pac_new = round( pac × 标准功率(mW) / power_mw )
```

计算后 clamp 到 `[1, 65535]`，再按 4.2 节格式下发。

> 示例：某档标准源为 220V / 0.36A / 79.2W。设备上报 voltage_mv=230000、current_ma=108、power_mw=24000、iac=0xCAA1、uc=0xA576、pac=0xAC27，则：
> - `iac_new = round(0xCAA1 × 360 / 108)`
> - `uc_new = round(0xA576 × 220000 / 230000)`
> - `pac_new = round(0xAC27 × 79200 / 24000)`

## 6. 错误处理

- 上位机下发帧长度 < 7、或 cmd ≠ `0x02`、或任一系数为 0 时，设备返回 `result=1`。
- 设备写入寄存器失败时，返回 `result=1`。
- 建议上位机在收到 `result=0` 前保留重发逻辑；写入成功后设备会自动重启，连接随之断开。

## 7. 上位机开发要点

- 多字节整数按**小端**读写（多数平台直接 `memcpy` 到 `uint16_t`/`uint32_t` 即可，但跨平台请显式按字节拼接）。
- 先订阅 Notify（`0x0002`）再等测试数据，否则收不到上报。
- 测试数据约 1s 一帧，上位机可连续收几帧求平均再计算，减小抖动。
- 写入成功后设备约 500ms 内复位，上位机无需主动断开。
